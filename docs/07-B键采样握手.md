# B键采样握手（2026-10-20 当前版）

30秒计时及timeout触发已从执行代码移除。遥操持续多久都不会自动采样或归位。
每轮仅由原right_init入口产生的B键事件触发，重复B只处理一次。

```text
示范成功 → arm_round(capture_trigger=button)
实际遥操开始 → started（仅记录会话，不计时）
B键 → button → pause_for_sample → paused
    → 读取实际姿态、锁定评分并发布score
    → reset_after_sample → 原驱动归位 → reset_done
```

内部Topic仍为 `teleop_event` 与 `teleop_control`，前缀均为
`/sflare_os/game/imitate/`，类型std_msgs/msg/String。所有事件都须匹配round_id，
采样及归位确认还须匹配session_id/request_id。reason仅接受button。

- arm_round不再含timeout_sec，改为capture_trigger:"button"。
- started不再要求started_monotonic，只提供round_id/session_id/event:"started"。
- 没按B时，不产生pause_for_sample、score或reset_after_sample。
- B键触发后，暂停确认5秒、采样15秒、归位确认45秒的故障保护仍保留。
  这些超时只报错并停止流程，不触发采样或自动归位。
- 急停、旧轮次、重复事件及采样失败不放行归位。
- SDK、评分公式、动作轨迹和公开Topic协议不改。

原驱动仍未消费上述握手，真实B键链路尚未完成；没有更换驱动二进制。
旧版06文档仅为历史记录，其中30秒和timeout要求不再适用。
