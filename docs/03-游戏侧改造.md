# 游戏侧改造记录

> **历史文档**：旧 Service 接口（`/sflare_os/game/command`、`moveaction`）已被 [API.md](../API.md) 的 Topic 接口取代。

日期：2026-10-19

## 1. 改造目标

游戏节点不再直接驱动机械臂，改为**调用固定动作服务**：

- 运动：发布动作名到 `/dual_arm_xcdl_action`，等状态 `busy → ready`
- 标准姿态：取 `config/actions.yaml` 的 `standard_deg`（= 动作最后一个非零关键帧）
- 脱限：`release_limit` 代理为动作服务的 `recover_limit`；`moveaction` 自检发现超限时自动先脱限
- 评分：`/arm_joint_states` + 权重表，逻辑不变
- 停止：发布 `"stop"`

## 2. 命令契约

| 请求 | 行为 | 备注 |
|---|---|---|
| `self_check` | 只读控制器 + 附带 `action_service_status` | 不再直接用于运动 |
| `moveaction` | 随机选一个候选动作 | 最近两次不重复 |
| `moveaction:like` | 指定动作名 | 冒号后为动作名 |
| `release_limit` | 代理 `recover_limit`；无超限返回 `NOT_REQUIRED` | 不再自己 Jog |
| `calculate_score` | 不变 | |
| `stop` | 发布 `"stop"` | |

`moveaction` 成功返回：

## 3. 新增错误码

| 码 | 场景 |
|---|---|
| `SERVICE_UNAVAILABLE` | 未收到状态 / `connection_failed` / `handle_busy` |
| `POWER_NOT_READY` | 服务 `power_not_ready` |
| `ACTION_NOT_STARTED` | 发命令后未进入 busy |
| `ACTION_TIMEOUT` | 动作超时 |
| `ACTION_REJECTED` | `invalid_target` / `unknown_command` / `single_not_support` |
| `ACTION_FAILED` | `failed` / `fatal_network` |
| `UNKNOWN_ACTION` | 请求的动作名不在动作表中 |

## 6. 部署注意

1. `setup.py` 的 `data_files` 已用 `glob('config/*.yaml')`，`actions.yaml` 会自动安装。
2. 真机模式需要 PallasSDK 共享库：部署时把 `libPallasSDK.so`（2.0.5355）放回包内，或设置
   `PALLAS_SDK_LIB=/usr/local/lib/PallasSDK/libPallasSDK.so`。
3. 游戏节点真机模式与动作服务**不能同时**自建控制器连接：游戏的 `self_check` 只在服务
   `ready` 时连接，窗口很短；动作服务执行期间游戏不会连控制器。
