## 3. 先订阅输出

终端C：

```bash
ros2 topic echo /sflare_os/game/imitate/result std_msgs/msg/String --full-length
```

如需独立查看握手，另开终端：


result根据type区分：arm_demo是动作阶段，arm_power是on/off电源状态，score是评分。

## 4. 查询与自检

操作终端（先执行第1节）：

```bash
ros2 topic pub --once /sflare_os/game/imitate/cmd std_msgs/msg/String \
  '{data: "{\"cmd\":\"acts\",\"args\":{}}"}'

ros2 topic pub --once /sflare_os/game/imitate/cmd std_msgs/msg/String \
  '{data: "{\"cmd\":\"arm_check\",\"args\":{}}"}'
```

acts应返回实际动作列表；arm_check的msg为空表示本次自检正常，非空先处理说明，不继续运动。
本项目arm_check使用只读检查路径，不用于主动执行恢复运动。

## 5. 示范指令（会运动）

若只验证示范，可直接执行本节；若还要采样评分，**先启动第6节辅助程序，再发本节命令**，让辅助程序接收新的arm_round。

```bash
ros2 topic pub --once /sflare_os/game/imitate/cmd std_msgs/msg/String \
  '{data: "{\"cmd\":\"arm_demo\",\"args\":{\"act_name\":\"点赞\"}}"}'
```

换动作时仅替换act_name：

| 显示名 | 可使用的英文名 |
|---|---|
| 点赞 | like |
| 指向 | diagonal_point |
| 握手 | handshake |
| 前伸递物 | handover |
| 举手过头 | raise_head |
| 疑问 | doubt |

正常阶段：start → moving → still（目标姿态展示5秒）→ reset → end。
部分动作有多次moving；still每个游戏动作只出现一次。
另有arm_power的on/off消息，不属于arm_demo阶段。失败不发送成功end。
动作逐个执行，上一动作未完成前不要重复发送。

## 6. 单次采样评分辅助指令（不调用归位）

本节辅助程序只创建Topic发布者/订阅者，不调用SDK、fish服务，不发布arm_demo或运动指令。
它会在操作者明确确认静止后模拟started/button，并自动回传paused，免去手动复制Q编号。
仅用于无实际遥操输出的静态评分验证，**不能代替生产客户端真实暂停确认**。
不要在有其他客户端参与同一轮握手时运行。

执行顺序：

1. 新开终端，加载第1节环境，运行下面完整代码。
2. 看到“等待新的arm_round”后，在另一个终端发送第5节示范命令。
3. 辅助程序拿到本轮编号后等待输入；等示范完成，确保当前姿态静止、没有遥操输出。
4. 输入 `SAMPLE` 才触发采样。无需先接入真实遥操；不要求人工搬动或改变机械臂姿态。
5. 观察score中的score、j1至j7；辅助程序不会执行归位，也不会虚报reset_done。

```bash
python3 - <<'PY'
import json
import threading
import time
import uuid
import rclpy
from rclpy.node import Node
from std_msgs.msg import String

rclpy.init()
node = Node('manual_score_helper_' + uuid.uuid4().hex[:8])
pub = node.create_publisher(String, '/sflare_os/game/imitate/teleop_event', 20)
state = {'round': None, 'session': 'manual_' + uuid.uuid4().hex,
         'request': None, 'active': False, 'score': None, 'permit': False, 'error': None}
lock = threading.RLock()

def send(data):
    msg = String()
    msg.data = json.dumps(data)
    pub.publish(msg)

def control(msg):
    data = json.loads(msg.data)
    with lock:
        if data.get('command') == 'arm_round':
            if state['active']:
                state['error'] = '轮次已变化，停止本次辅助采样'
            else:
                state['round'] = data['round_id']
            return
        if not state['active'] or (data.get('round_id'), data.get('session_id')) != (state['round'], state['session']):
            return
        if data.get('command') == 'pause_for_sample' and state['request'] is None:
            state['request'] = data['request_id']
            send({'event': 'paused', 'round_id': state['round'],
                  'session_id': state['session'], 'request_id': state['request']})
        elif data.get('command') == 'reset_after_sample' and data.get('request_id') == state['request']:
            state['permit'] = data.get('sampled') is True and data.get('allow_reset') is True
        elif data.get('command') == 'stop_without_reset':
            state['error'] = '收到停止通知'

def result(msg):
    data = json.loads(msg.data)
    with lock:
        if not state['active']:
            return
        if data.get('type') == 'score' and state['request'] is not None:
            state['score'] = data
            print(json.dumps(data, ensure_ascii=False, indent=2), flush=True)
        elif data.get('type') == 'error':
            state['error'] = json.dumps(data, ensure_ascii=False)

node.create_subscription(String, '/sflare_os/game/imitate/teleop_control', control, 20)
node.create_subscription(String, '/sflare_os/game/imitate/result', result, 50)
worker = threading.Thread(target=rclpy.spin, args=(node,), daemon=True)
worker.start()
registered = False
try:
    print('等待新的arm_round；请在另一个终端发起一次示范。', flush=True)
    deadline = time.monotonic() + 180
    while state['round'] is None:
        if time.monotonic() > deadline:
            raise RuntimeError('未收到新轮次，未触发采样')
        time.sleep(.1)
    chosen = state['round']
    print('本轮：' + chosen, flush=True)
    if input('确认示范已完成、机械臂静止且无遥操输出，输入 SAMPLE：').strip() != 'SAMPLE':
        raise RuntimeError('未确认静止，未触发采样')
    with lock:
        if state['round'] != chosen:
            raise RuntimeError('轮次发生变化，请重新运行辅助程序')
        state['active'] = True
        send({'event': 'started', 'round_id': chosen, 'session_id': state['session']})
        registered = True
    time.sleep(.3)
    send({'event': 'button', 'round_id': chosen, 'session_id': state['session']})
    deadline = time.monotonic() + 22
    while not (state['score'] is not None and state['permit']):
        if state['error']:
            raise RuntimeError(state['error'])
        if time.monotonic() > deadline:
            raise RuntimeError('等待评分/许可超时，不执行归位')
        time.sleep(.05)
    print('采样评分完成；本辅助程序不调用right_init。', flush=True)
except (KeyboardInterrupt, EOFError, RuntimeError) as exc:
    print(str(exc), flush=True)
finally:
    if registered:
        send({'event': 'cancelled', 'round_id': chosen, 'session_id': state['session']})
        time.sleep(.3)
    rclpy.shutdown()
    worker.join(timeout=3)
    node.destroy_node()
PY
```

辅助程序最后发送cancelled以结束无归位会话；当前协议会伴随一条取消相关error以及stop_without_reset。
这是本辅助流程的主动终止，不是伪造归位完成。不要将error当作评分字段，已收到的score另行读取。
如果游戏未接受本轮请求，辅助程序不会强行重置游戏状态或发送新的示范。

## 7. 实际B键客户端接入后的归位

本说明不提供立即执行的right_init命令，避免评分尚未锁存时误触发归位。
生产客户端须按 [接口文档](../API.md) 消费匹配的reset_after_sample后再调用原服务，并依据真实结果发送reset_done。
第6节辅助程序的自动paused仅限操作者已确认静止的单次评分，不应复制为实际遥操的暂停实现。

## 8. 结束

辅助程序自行退出；echo窗口用Ctrl+C关闭。需要停止本次手工启动的游戏/动作节点时，在各自启动终端Ctrl+C。
节点退出不代替实体急停；运动异常优先使用现场停机保护，不以普通Topic命令替代急停。
